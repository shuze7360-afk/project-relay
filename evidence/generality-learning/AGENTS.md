## 接力规则（接手者必读）
- 任务状态只有五种：待做 / 进行中 / 待验收 / 完成 / 阻塞。
- 待验收 → 完成必须附证据（产物路径 + 验证命令/输出或用户确认）；"已生成"≠"已完成验收"。
- 下一步四要素：行动、所需输入、预期产物、完成条件。
- 更新时机：完成可验收步骤 / 关键决定变化 / 遇阻塞 / 交接前 / 中断恢复核对后；不必等用户要求"保存进度"。
- 记录与实际冲突：以实际为准，先修正记录再继续。
- 授权边界：跑实验、改代码、写草稿可直接做；花钱（云 GPU）与修改核心指标口径需先确认用户。

## 纪律
- 实验必须固定随机种子并保存划分快照，否则不能标"可复现"。
- 实验数字只写入 LOG-experiments.md 并注明命令与时间，STATE.md 引用其结论。
