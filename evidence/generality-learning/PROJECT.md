# PROJECT — 硕士论文：联邦学习非IID通信效率优化

## 目标与背景
【事实·用户】完成硕士毕业论文：联邦学习在非IID数据划分下的通信效率优化，产出论文初稿与可复现的支撑实验。
【假设】预计明年春季校内盲审（用户未给具体日期，见待确认）。

## 范围
做：FedAvg/FedProx 基线复现；改进方法（梯度稀疏化 + 误差反馈）实验与消融；论文撰写。
不做：新方法的理论收敛性证明；会议投稿；跨设备（iot 规模）仿真。

## 交付物与验收标准
1. 基线复现：固定 3 个随机种子，FedAvg 在 CIFAR-10 非IID（Dirichlet α=0.1）下最终准确率与文献报告偏差 ≤2%。验收：实验记录中留有 3 组种子的结果表与运行命令。
2. 改进方法实验：目标通信量下降 ≥30% 且准确率下降 ≤1%（相对复现基线）。验收：对比表 + 收敛曲线图写入实验记录。
3. 论文初稿：5 章齐全（绪论/相关工作/方法/实验/总结）。验收：导师预审意见返回且无结构性否定。
