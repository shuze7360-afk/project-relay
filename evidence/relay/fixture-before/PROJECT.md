# PROJECT — wordcount 小工具工程化

## 目标与背景
【事实·用户】给现有脚本 wordcount.py 补齐工程化：README、单元测试、打包配置，最终在本地完成一次可安装性验收。发布到 PyPI 属外部动作，需另行确认。

## 范围
做：README.md、tests/、pyproject.toml、本地构建验收。
不做：CI 配置修改、文档站、对外发布（见阻塞任务）。

## 交付物与验收标准
1. README.md：含"简介 / 安装 / 用法示例"三节。验收：打开文件三节齐全、示例可照做。
2. 测试：tests/ 下 ≥3 个用例且全部通过。验收：`python -m unittest discover` 输出 OK。
3. pyproject.toml：本地 `pip install .` 成功（或记录明确不采用的理由与替代方案）。验收：命令退出码 0。
4. （阻塞·需用户）发布 PyPI：用户提供 token 后另行执行，不在本次范围。

## 约束与授权
- 允许直接执行：修改 wordcount.py、tests/、pyproject.toml、README.md；运行测试与本地构建。

- 时间：无硬期限。
