# PROJECT — reportcli 新增 xlsx 导出

## 目标与背景
【事实·用户】为内部 CLI 工具 `reportcli`（Python 3.10+）新增 `report export --format xlsx` 子命令，与既有 CSV 导出并列。

## 范围
做：xlsx 导出功能（表头加粗、数值列按数字格式写入）、单元测试、README 用法补节。
不做：PDF 等其他格式；修改既有命令行为；任何 GUI。

## 交付物与验收标准
1. `report export --format xlsx <数据文件>` 生成合法 xlsx。验收：用 3 份真实数据文件导出并人工抽查打开无异常（用户抽查确认）。
2. 单元测试覆盖导出函数主要分支（空数据、含中文表头、数值/文本混合）。验收：测试命令全绿【假设：CI 测试命令待确认，见待确认】。
3. README 增补用法一节。验收：含示例命令与输出说明。
